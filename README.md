# GRAND VOYAGE — карусель: замена логотипа

Логотип на всех пяти слайдах был вшит в картинку и на каждом слайде выглядел
по-разному (разное число лучей у солнца, разная форма волн, разный шрифт
надписи), а на слайде 5 он вообще превратился в зелёное пятно. Поэтому старый
логотип **удалён** со всех слайдов, а настоящий логотип **нарисован заново** —
в одном и том же месте, одного размера, одного цвета.

## Что получилось

| | |
|---|---|
| Позиция логотипа | `x = 104, y = 46` (одинаково на всех слайдах) |
| Размер логотипа | `205 × 124 px` |
| Размер слайда | `1254 × 1254 px` |
| Цвета | солнце — золотой градиент оригинала, волны и надпись — `#414C89` |

Логотип стоит слева, чуть выше заголовка, и на всех слайдах — пиксель в пиксель
на одном месте.

## Папки

```
source/   исходные слайды (без изменений)
logo/     логотип: PNG с прозрачным фоном + SVG
output/   готовые слайды (PNG без потерь + JPG q95)
scripts/  код, которым всё это сделано
```

### `output/`

- `01..05_*.png` / `.jpg` — вариант с **оригинальными цветами** логотипа
  (тёмно-синяя надпись), как и просили.
- `01..05_*_white.png` / `.jpg` — запасной вариант, где надпись и волны белые.
  Солнце в обоих вариантах одинаковое.

Белый вариант заметно читабельнее на синем небе: контраст надписи с фоном
получается ~3.6:1 против ~2.2:1 у тёмно-синей. Выбор за вами — оба комплекта
готовы.

### `logo/`

Логотип с прозрачным фоном, отрисованный отдельно под каждый размер
(не растянутый из маленького):

```
grand_voyage_brand_205.png    grand_voyage_white_205.png
grand_voyage_brand_410.png    grand_voyage_white_410.png
grand_voyage_brand_820.png    grand_voyage_white_820.png
grand_voyage_brand_1600.png   grand_voyage_white_1600.png
grand_voyage_brand.svg        grand_voyage_white.svg
```

SVG масштабируется без потерь — для печати, баннеров, сайта.

## Как это сделано

**Логотип.** Единственный источник — скриншот аватарки из Instagram, где
рисунок занимает всего ~352 × 220 px и размыт JPEG-ом. Простое увеличение дало
бы мыло, поэтому логотип **векторизован**: каждый пиксель разложен на «краску
поверх белого фона», контуры золота и тёмно-синего обведены через potrace, а
цвет взят из исходника отдельным сглаженным полем — так градиент солнца
сохранился точно. Дальше логотип рисуется заново сразу в нужном размере
с 4-кратным суперсэмплингом, поэтому края гладкие и чёткие, а не растянутые.

**Удаление старого логотипа.** Маска строится по самой краске (золото / белое /
тёмно-синее относительно локального цвета неба), затем область закрашивается
решением уравнения Лапласа с граничными условиями из соседних пикселей. Решение
точно совпадает с границей, поэтому шва нет, а небо за логотипом — гладкий
градиент, так что и размазывать нечего. Проверка: остаточная структура в бывшей
зоне логотипа — 3.6 из 255, то есть ровное небо.

**Слайд 5.** Вне повреждённого угла слайды 4 и 5 — одна и та же картинка
(различия ниже уровня JPEG-шума), поэтому угол с зелёным пятном перенесён со
слайда 4 с растушёвкой и подгонкой экспозиции, а не дорисован.

## Запуск

```bash
pip install pillow numpy opencv-python-headless potracer scipy
cd scripts
python3 build_logo.py           # векторизовать логотип из скриншота
python3 export_logo_assets.py   # выгрузить PNG + SVG
python3 rebuild_slides.py       # пересобрать слайды (вариант brand)
python3 -c "import rebuild_slides as R; R.run('white')"
```

Координаты в `rebuild_slides.py` заданы относительно холста 1254 px и
пересчитываются автоматически — если найдутся оригиналы в большем разрешении,
достаточно положить их в `source/` и перезапустить.

## Важно про качество исходников

Слайды в `source/` получены из версий, присланных в чат (1254 × 1254, пережаты
в WebP). Логотип нарисован заново и от этого не пострадал, но фотографии на
слайдах остаются такими, как пришли. Если есть оригиналы в большем разрешении —
положите их в `source/` под теми же именами и перезапустите `rebuild_slides.py`,
результат будет лучше.

Слайды 4 и 5 — это один и тот же макет («Приходите в наш офис!»); слайд 5 был
его испорченной копией. Оба выложены в `output/`, но в карусель, скорее всего,
нужен только один.
